# Product

## Platform

web

## Users

A personal browser for choosing films and whole series from German subscriptions.
This usage context is inferred from README.md and the user's project guidance.

## Product Purpose

Find unseen subscription titles ranked by genuine IMDb ratings before pagination.

## Capabilities and Constraints

FastAPI serves plain HTML, CSS and JavaScript. SQLite persists preferences and history.
Preserve all subscriptions, automatic filters, movie/series lists, watched/hidden actions,
undo, refresh, pagination and coverage information. Use only the real catalog and posters.
Credentials remain server-only. Preserve keyboard operation and mobile browsing.

## Brand Commitments

Wanna Watch. The user requested an amazing 80s retro design with a wow effect.

## Evidence on Hand

README.md, docs/usage.md, existing interface and the local real catalog.

## Design exploration

The user wants to compare neon video store, analog video club, and arcade after dark
as image concepts before choosing the implementation. The user approved Neon video store. Build to match .impeccable/mocks/neon-video-store.png.
